# Claude Themes

20 animated backgrounds for the Claude desktop app. A pixel lagoon, a koi pond, a riso sunrise, northern lights, an amber departure board, and more. One command switches between them.

## Install

**In the Claude desktop app:** click **+** next to the prompt box, then **Plugins**. Choose **Add marketplace** and enter `buildwithdesi/claude-themes`. Then choose **Add plugin** and pick `custom-theme`.

**At the prompt of a Claude Code terminal session:**

```
/plugin install custom-theme --marketplace buildwithdesi/claude-themes
```

Answer `y` to add the marketplace, then press Enter to install for your user.

**From a shell:**

```bash
claude plugin install custom-theme --marketplace buildwithdesi/claude-themes
```

## Use

| Type | What happens |
| --- | --- |
| `/custom-theme` | Shows the theme that is on, and every theme |
| `/custom-theme <name>` | Turns one on. Part of a name works: `honu`, `dunes night` |
| `/custom-theme random` | Picks one for you |
| `/custom-theme next` | Steps through the list |
| `/custom-theme off` | Goes back to the app's own look |

Your pick is saved. New sessions open with it, and sessions you already have open switch to it within a few seconds.

## Good to know

- The backgrounds draw in the Claude desktop and mobile apps. A plain terminal session keeps its normal look.
- A light theme switches the app to light mode while it is on. A dark theme switches it to dark mode.
- `/custom-theme off` gives you the app's own look back at any time, in every open session.
- Running another theme mod too? Your pick still wins when a session starts. If you switch that mod on with its own command, this pack turns itself off everywhere.
- `tools/preview.mjs` is an optional script for people who make themes. The themes never run it. It needs Node and Python.
